TRUST BY DESIGN

A source is not automatically a fact.

EngramVault separates what a source says from what you have confirmed. That makes it possible to remember your history without treating an old note or an AI answer as permanent truth.

EVIDENCE

A conversation, note, or document with provenance.

CLAIM

An attributed suggestion or unverified statement.

FACT

A current state you have confirmed.

DECISION

A choice that can be adopted, revised, or superseded.

04

SELF-HOST

Running in two minutes.

EngramVault is a single Docker container. No cloud account, no subscription, no data leaving your machine.

QUICK START 
# Run official multi-arch container
docker run -d \
  --name engramvault \
  -p 5006:5006 \
  -v ./vault:/data \
  gaskb/engramvault:latest

# Or clone from GitHub
git clone https://github.com/gaskb/engramvault.git
